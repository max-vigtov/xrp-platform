# XRP Platform - Business Management System

A robust enterprise management platform built with Laravel 10, designed to handle business operations efficiently. The system includes:

## Key Features
- Inventory Management
- Sales and Purchase Control
- Customer and Supplier Management
- Product and Category Management
- Role and Permission System
- Intuitive Dashboard

## Technologies
- Laravel 10
- PHP 8.1+
- Spatie Laravel Permission
- Integrated Authentication System
- Responsive Interface

## Technical Features
- MVC Architecture
- Role and Permission System
- RESTful API
- Secure Session Management
- Custom Error Handling

## Requirements
- PHP 8.1 or higher
- Composer
- MySQL/MariaDB
- Node.js and NPM

## Installation
1. Clone the repository
2. Install dependencies with Composer
3. Configure .env file
4. Run migrations
5. Start the server
